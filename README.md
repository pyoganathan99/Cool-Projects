# Cool-Projects

A collection of cool and useful projects, resources and websites.

## Client side

### MicroLighter

https://davatron5000.github.io/microlighter/

A frontend library for syntax highlighting, with a twist! Use the modern `::highlight()` pseudo element instead of
wrapping code blocks in a lot of `<span` elements. Very lightweight and lazily loadable too.

### Cobe

https://cobe.vercel.app/

Cool looking WebGL based globe rendering library with a lot of customisation options. 

### drawably

https://www.drawably.dev/

For UI form controls that look like they were drawn by hand.

## UI/UX

### ui sfx

https://uisfx.com/

A collection of source samples for UI interactions.

### Canvas UI

https://canvasui.dev/

A library using html-in-canvas feature for awesome interactive visual effects like floating bubbles, warp, flames, etc.

## Static Site Generators

### Docusaurus

A React based static site generator.

### VitePress

https://vitepress.dev/

A Vue based static site generator.
